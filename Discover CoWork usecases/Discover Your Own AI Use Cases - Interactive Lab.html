THE METHOD

Evidence → experiment → learning

1. Discover from real work

Use accessible business activity. An invitation is not attendance; a recently opened file is not authorship. Ask for source titles, dates and references.

2. Test a small outcome

Choose a bounded source set, a new output, human review and a stop condition. Missing retrieved evidence is not proof of a missing capability.

3. Share the method

Share a sanitised pattern, prompt, review method and observed learning—not source correspondence, tenant links or private project details.

Cowork and Work IQ are not interchangeable interfaces

Cowork is an execution experience for multi-step work. Work IQ provides permission-aware work context in supported experiences. Available sources, file creation, scheduling and actions vary. Ask the experience what it can actually do and check organisational policy.

When should a task become recurring?

Only after a bounded test is reliable and scheduling is supported and permitted. Specify sources, look-back window, destination, missing-source handling, no-new-information behaviour and human review. This prototype never creates schedules.
